# White-label boxed product docs

This folder is the operating and tech plan for selling **multi-product-ecom** as a white-label store: you host it, you pick the theme, the store owner only runs the shop.

Start here:

1. [white-label-boxed-product-plan.md](white-label-boxed-product-plan.md) — master plan (decisions, current code, phases)
2. [business-model.md](business-model.md) — what you sell, packages, what the owner does
3. [roles-and-permissions.md](roles-and-permissions.md) — `super_admin` vs `store_owner`
4. [themes.md](themes.md) — theme catalog and completeness checklist
5. [onboarding-checklist.md](onboarding-checklist.md) — how you launch a new store
6. [owner-guide.md](owner-guide.md) — one-page guide to give the client
7. [roadmap.md](roadmap.md) — implementation order

Do not start coding until Phase 1 on the roadmap is explicitly started. Existing live stores (for example shohojkenakata) stay as they are until roles are implemented carefully.
