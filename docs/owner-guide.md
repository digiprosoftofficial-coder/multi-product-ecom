# Store owner guide

Short guide for the shop owner. Super admin sets up the site. You run the shop.

## Login

Open `https://your-domain.com/login` with the email we gave you.

You will see the admin dashboard. You will **not** see Themes or design settings. That is intentional.

## Daily work

**Products**

- Add a product: name, price, stock, category, photos
- If stock is 0, customers cannot buy it
- Hide a product instead of deleting it if you might sell it again

**Orders**

- New orders appear under Orders
- Open an order to see items, phone, address, payment
- Change status when you pack or ship
- Print / download the invoice if you need it

**Messages**

- Contact form messages appear under Messages
- Mark them read after you reply (WhatsApp / phone)

**Reports**

- Use Reports to see sales for a date range

## What to message us for

- Logo, colors, homepage banner, slider
- Theme change
- Payment number or delivery charge change
- Domain / email / site down
- A new page or a new feature

## What not to do

- Do not share your admin password
- Do not ask hosting support to edit code
- Do not delete orders to “fix” a mistake — change status or ask us
